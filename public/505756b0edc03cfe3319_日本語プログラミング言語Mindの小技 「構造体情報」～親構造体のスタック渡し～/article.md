# はじめに
日本語プログラミング言語Mindの小技「構造体情報」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# この小技に関連するMind言語マニュアル

この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載があります。
１０ 構造体・型紙
└型紙
　└親構造体のスタック渡し

>　「＜親構造体＞の　＜型紙要素＞」という親子ペアの表記が基本ではあるものの、親構造体（の情報）はスタックに積まれていれさえすれば良いので柔軟なプログラムを書ける。
>
>　（プログラム例）
>生徒名一覧表示とは　（構造体情報　→　・）
　　　　　　　　成績簿情報は　構造体情報
　　　　成績簿情報に　入れ
　　　　個人データの　要素数を
　　　　回数指定し　　　　　↓生徒番号の表示
　　　　　　　　回数を　二桁で数値表示し　空白表示し
　　　　　　　　成績簿情報の　生徒名（回数）を　一行表示し
　　　　繰り返すこと。　　　　　　↑生徒名の表示
    ～略～
>
>上記では「構造体情報」という見慣れない変数型が使われている。これは文字列情報（定義文で言えば「○○は　文字列」）とほぼ同じものなのだが、特に構造体を指す情報であることが分かるようにこのようなデータ型名称を設けている。（構造体の実体がスタックに積まれるわけではなく、そこを指す情報がスタックに詰まれて本処理単語が呼び出されるという想定である）


本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。

# 対応バージョン
■Mind７　■Mind８　■Mind９
■Windows版　□Linux版

# 小技の解説
この記事の取り扱う「構造体情報」は構造体の実体がスタックに積まれるわけではなく、そこを指す情報がスタックに詰まれるという想定です。ユーザー定義単語内のローカル変数として「構造体情報」を宣言して、スタックから（ソースコード上はユーザー定義単語の直前に記述された構造体名から）その構造体情報変数に代入した場合、他のプログラミング言語の構造体の参照渡しに近いイメージとも言えそうです。

公式マニュアルに記載があるとおり、これは文字列情報（「○○は　文字列」）とほぼ同じですが、特に構造体を指す情報であることが分かるようにこのようなデータ型名称が設けられています。


# Mindプログラムソース

```mind:implicitstructure.src
結果セット型は　型紙
        言語IDは　変数
        言語名は　文字列実体　長さ　200
        公開年は　変数
        よみがなは　文字列実体　長さ　200
    行データは　言語IDと　言語名と　公開年と　よみがな
    全体は
　　    4行の　行データ。

初期化とは　（構造体情報　→　・）
        結果セット情報は　構造体情報

    結果セット情報に　入れ
    行データの　要素数で　回数指定し
        結果セット情報の　言語ID(回数)に 回数を　入れ
    繰り返す
    結果セット情報の　言語名(1)に 「Mind version 1」を　入れ
    結果セット情報の　言語名(2)に 「Mind version 7」を　入れ
    結果セット情報の　言語名(3)に 「Mind version 8」を　入れ
    結果セット情報の　言語名(4)に 「Mind version 9」を　入れ
    結果セット情報の　公開年(1)に 1985を　入れ
    結果セット情報の　公開年(2)に 1997を　入れ
    結果セット情報の　公開年(3)に 2017を　入れ
    結果セット情報の　公開年(4)に 2026を　入れ
    結果セット情報の　よみがな(1)に 「まいんどばーじょんいち」を　入れ
    結果セット情報の　よみがな(2)に 「まいんどばーじょんなな」を　入れ
    結果セット情報の　よみがな(3)に 「まいんどばーじょんはち」を　入れ
    結果セット情報の　よみがな(4)に 「まいんどばーじょんきゅう」を　入れること。

出力とは　（構造体情報　→　・）
        結果セット情報は　構造体情報

    結果セット情報に　入れ
    行データの　要素数で　回数指定し
        結果セット情報の　言語ID(回数)を　数値表示し　「|」を　表示し
        結果セット情報の　言語名(回数)を　表示し　「|」を　表示し
        結果セット情報の　公開年(回数)を　数値表示し　「年|」を　表示し
        結果セット情報の　よみがな(回数)を　表示し　「|」を　表示し　改行し
    繰り返す。

メインとは　（・　→　・）
        結果セットは　構造体　結果セット型
        
    結果セットで　初期化し
    結果セットで　出力すること。
```

「初期化する」と「出力する」の定義では、構造体情報がスタックから渡されると定義され、結果セットの構造体情報はメインのローカル変数として宣言されて、それぞれの単語の直前でスタック渡しするように記述されています。

「初期化する」と「出力する」の定義では、厳密には属性設定した方が望ましいですが、本記事では割愛しています。
