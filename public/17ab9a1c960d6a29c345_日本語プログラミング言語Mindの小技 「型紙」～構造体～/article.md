# はじめに
日本語プログラミング言語Mindの小技「型紙」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# この小技に関連するMind言語マニュアル

この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載があります。
１０ 構造体・型紙　型紙
└型紙
　└型紙の定義
 
>　構造体を定義すると、内部の変数や集合の組み合わせとして「型」の定義が行われるが、同時にそのための「領域確保」も行われる。この２つを分離し、「型の定義」と「領域確保」を別にするための概念が「型紙」である。
　この方法をとる利点としては、１つの型紙を使って複数の構造体を定義（実体を獲得）することができることが挙げられる。
注
他の言語、たとえばＣ言語で言うところの構造体は、Mindにおいては型紙に相当する概念であり、この点で用語の違いがある。

>型紙の定義　
　型紙は構造体の機能のうち、型だけを定義するものである。
　定義の規則はほとんど構造体定義と同じであり、次のような形式で定義する。

>　　（型紙の定義）
>
>構文＝
＜型紙名＞は　型紙
　　　　　　　　　　　　＜変数名＞は　　・・・
　　　　　　　　　　　　＜変数名＞は　　・・・
　　　　　　　　＜集合名＞は　・・と　・・と　・・
　　　　　　　　＜集合名＞は　・・と　・・と　・・
　　　　全体は
　　　　　　　　・・・と　・・・と　・・・。
　型紙はそれだけでは実体を持たないので、上記と別に実体を確保するための宣言が必要となる。そのためには、「○○は　構造体」の拡張機能として以下のような記述を使う。
>
>　　（実体の定義）
>
>構文＝
＜構造体名＞は　構造体　＜型紙名＞。



本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。

# 小技の解説
「型紙」はMindの構造体定義においてインスタンス生成（メモリ上の実体確保）を除いた型情報の定義のみをすることを意味する機能です。

マニュアルにも注意事項として記載がありますが、Mindの言語仕様の用語としての「構造体」はインスタンス生成がセットになっている機能を意味しますので他のプログラミング言語ご経験者にとっては注意が必要です。

「型紙」で構造体の型構造を定義した後、実際に使用する実体変数をその型情報で宣言するという、どちらかというと一般的な静的型付け言語の手順を踏むのがこちらです。サンプルを使って説明します。

# Mindプログラムソース

```mind:katagami.src
結果セット型は　型紙
        言語IDは　変数
        言語名は　文字列実体　長さ　200
        公開年は　変数
        よみがなは　文字列実体　長さ　200
    行データは　言語IDと　言語名と　公開年と　よみがな
    全体は
　　    4行の　行データ。

結果セットは　構造体　結果セット型。

結果セット初期化とは　（・　→　・）
    行データの　要素数で　回数指定し
        結果セットの　言語ID(回数)に 回数を　入れ
    繰り返す
    結果セットの　言語名(1)に 「Mind version 1」を　入れ
    結果セットの　言語名(2)に 「Mind version 7」を　入れ
    結果セットの　言語名(3)に 「Mind version 8」を　入れ
    結果セットの　言語名(4)に 「Mind version 9」を　入れ
    結果セットの　公開年(1)に 1985を　入れ
    結果セットの　公開年(2)に 1997を　入れ
    結果セットの　公開年(3)に 2017を　入れ
    結果セットの　公開年(4)に 2025を　入れ
    結果セットの　よみがな(1)に 「まいんどばーじょんいち」を　入れ
    結果セットの　よみがな(2)に 「まいんどばーじょんなな」を　入れ
    結果セットの　よみがな(3)に 「まいんどばーじょんはち」を　入れ
    結果セットの　よみがな(4)に 「まいんどばーじょんきゅう」を　入れること。

結果セット出力とは　（・　→　・）
    行データの　要素数で　回数指定し
        結果セットの　言語ID(回数)を　数値表示し　「|」を　表示し
        結果セットの　言語名(回数)を　表示し　「|」を　表示し
        結果セットの　公開年(回数)を　数値表示し　「年|」を　表示し
        結果セットの　よみがな(回数)を　表示し　「|」を　表示し　改行し
    繰り返す。

メインとは　（・　→　・）
    結果セット初期化し
    結果セット出力すること。

```
構造体定義の終端要素変数の、たとえば「言語名」にアクセスする際には、構造体名の装飾は必要です。

各メンバの要素数は各層で取得できますが、中間メンバ名の行データの要素数を参照する場合は、構造体名の装飾は不要という点が注意事項です。型情報の中で静的に定義された要素数は実体変数の内容ではないので、構造体名の装飾不要という仕様のようです。
