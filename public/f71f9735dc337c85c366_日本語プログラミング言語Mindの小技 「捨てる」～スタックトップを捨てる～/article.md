# この小技に関連するMind言語マニュアル

この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載があります。
１１ スタック操作
└スタック操作語
　└捨てる

>構文＝ ＜データ＞を　捨てる　→　・
>
> スタックにあるデータを１つ捨てるだけの機能である。上記で ＜データ＞ と抽象的に書いたのは、これが数値でも文字列でも、何でもいいからである。
　一旦、スタックにデータを積んだものの、不要になってしまったような場合（後述する「複写」したあとで不要になるというケースもある）に、その不要のデータを捨てて、スタックの後片付けをする目的で使用する。


本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。

# 小技の解説
この記事の取り扱う「捨てる」はスタック志向言語Forthの流れを汲む日本語プログラミング言語Mindの特徴的な機能です。

Mindの処理単語は予約済単語であれユーザー定義単語であれ、１つまたは複数の値・変数をスタックに積むことで、関数型プログラミング言語の戻り値のような動作を実現しています。

「捨てる」はスタックの最上位に積まれた値や変数を削除して、スタックポインタの位置を１つ手前に戻す処理を行います。

例えば、ある処理単語が２つの値をスタックに積んだとして、次の単語がスタックに積まれた値を処理してその単語がスタックに値を積まない場合、その単語を実行した後、「捨てる」を実行すると、最初の処理単語が積んだ１つ目の値が削除されます。

よくあるパターンは、ある処理単語が２つの値をスタックに積んだとして、積んだ順として最初の値がなんらかの結果で、次に積んだ値が処理単語の成功失敗の真偽だとすると、次の単語はまずスタック先頭の値を判定して手前の処理単語の実行結果が成功だったのか失敗だったかを分岐し、成功だった場合は次のスタックの値を何か次の処理単語うに使い、失敗だった場合はそのデータが不正なので次の処理には使わず「捨てる」を実行することで、スタックの整合性を維持することができます。


# Mindプログラムソース

```mind:throwaway.src
棚積みするは　無処理と　等価。

棚に荷物を二つ積むとは　（・　→　文字列１、文字列２）
    「これはＡ様のお荷物」を　棚積みし
    「これはＢ様のお荷物」を　棚積みすること。

棚から上の一つ目どかすとは　（文字列１、文字列２　→　文字列１）
    捨てること。

メインとは　（・　→　・）
    棚に荷物を二つ積み、
    棚から上の一つ目どかして、一行表示すること。
```
Mindにとってスタックに変数を置くという記述は根源的なものなので、とりあえず変数名を記述すればスタックに置くことになるのですが、このソースではその点わかりやすくするため、「棚に積む」という無処理単語を等価定義しています。

「棚に荷物を二つ積み」を実行したことにより、棚の状態は下図のような状態となっています。

｜「これはＢ様のお荷物」
｜「これはＡ様のお荷物」
└ーーーーーーーーーーーーーーーーー

「棚から上の一つ目どかす」では「捨てる」が実行されていますので、棚の状態は下図となります。

｜
｜「これはＡ様のお荷物」
└ーーーーーーーーーーーーーーーーー

「一行表示し」で一番上の「これはＡ様のお荷物」が使われるので下図の状態となり、

｜
｜
└ーーーーーーーーーーーーーーーーー

みなさんは、コンソールに表示されたお荷物の状態はイメージできましたでしょうか？

「棚から上の一つ目どかす」のスタック仕様のコメントですが、「棚に荷物を二つ積む」が文字列を２つスタックに積んだところからの処理をわかりやすくするため
>（文字列１、文字列２　→　文字列１）

と記述していますが、単語単体のIN／OUTとしては文字列１つを受け取ってなにも返さないとも言えるので、下記のように書くこともできます。

```mind:throwaway.src
棚から上の一つ目どかすとは　（文字列　→　・）
    捨てること。
```
