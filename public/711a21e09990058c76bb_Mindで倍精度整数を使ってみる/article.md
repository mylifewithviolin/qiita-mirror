# はじめに
諸般の流れから日本語プログラミング言語Mindで固定小数点計算機能を書いてみようかなと思い立ち、Mind開発者の@killyさんからMind8に倍精度整数があると伺ったのでさっそく使ってみました。


# お題のソースコード
```mind:decimal.src
int32は　変数。
int64は　倍精度変数。

メインとは
	int32に　2147483647を　入れ
	int32を　数値表示し　改行し
	int32を　NOTし　数値表示し　改行し
	int32を　1だけ　左シフトし　数値表示し　改行し
	int32を　1だけ　右シフトし　数値表示し　改行し
	改行し
	int64に　2147483647を　入れ
	int64を　数値表示し　改行し
	int64を　NOTし　数値表示し　改行し
	int64を　1だけ　左シフトし　数値表示し　改行し
	int64を　1だけ　右シフトし　数値表示し　改行し
	改行し
	int64を　＄＄クアド表示し　＄＄改行し
	int64を　NOTし　＄＄クアド表示し　＄＄改行し
	int64を　1だけ　左シフトし　＄＄クアド表示し　＄＄改行し
	int64を　1だけ　右シフトし　＄＄クアド表示し　＄＄改行。
```

倍精度整数の変数名はよくわからなかったので、「倍精度変数」としたらコンパイラ通過しました。ただし、普通に整数文字を代入するとデフォルトの32bit整数になっているようで、11桁以上の数値は代入できませんでした。

# お題のソースコード（改）
倍精度変数への代入方法を、「＄＄クアド表示」という便利単語を発見したsampleF\小数変数.srcというサンプルコードに書かれていた、文字列情報合成して代入する方法に書き換えてみます。

```diff:decimal.src
+	0ffffffffHと　099999999Hを　無処理し　文字列情報合成し　int64に　入れ
-	int64に　2147483647を　入れ
```

# 実行結果（改）
では実行してみましょう。
```
(コンパイル)
コンパイル中 .. 終了

(実行)
2147483647
-2147483648
-2
1073741823

-1
0
-2
2147483647

FFFFFFFF|99999999
00000000|99999999
FFFFFFFE|99999999
7FFFFFFF|99999999
```
「数値表示」は32bit部からしか出力できていないようですが、「＄＄クアド表示」では残り32bit部にも値が入ったことがわかります。
標準ビット操作単語は32bit部にのみ作用している感じ。
