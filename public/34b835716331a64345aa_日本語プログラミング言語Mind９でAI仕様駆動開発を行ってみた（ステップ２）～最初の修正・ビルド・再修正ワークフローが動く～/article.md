# はじめに
日本語プログラミング言語Mindのバージョン９でAI仕様駆動開発（っぽいこと）を行ってみます。本記事はその第２ステップで、まだこの記事でAI仕様駆動開発ができているわけではありません。

# 生成AI
## Microsoft Copilot
Windows11アプリケーションのMicrosoft Copilot。昨年末から日本語プログラミング言語あおい（Re:Mind）の原型を作成してもらった生成AI[^1][^2][^3]。モードは「無料プラン」。GitHub Copilotの使い方アドバイザーとして利用。
## GitHub Copilot
GitHub CopilotのPro版を導入。あおいの最小セット（MVP）実装後[^4]の検証で検証改修再検証フローを数回廻したところフリー版のクレジット足らなくなったのでPro版へアップグレード。スーパバイザとしてMicrosoft Copilotを使いGitHub CopilotのCodeAgent推論量を最小化するプロンプトをCopilotで生成しGitHub CopilotのCodeAgentで実行という工法？を採用しています。

## 完了レポート.md
本記事では初めてのAIによるMindソースコードのコンパイル可能な状態の生成ですので、完了レポート.mdを詳しくみていきます。
```text:result\firework修正ビルド完了レポート.md
# firework 修正ビルド完了レポート
## 結果
`firework.src` の修正とbuildを完了しました。
最終実行コマンド:

call C:\Mind9\usemind.bat && mind firework guilib

最終結果:

コンパイル中 .. 終了
Coping.. C:\Mind9\bin\mindexw.exe --> firework.exe

コンパイルエラーはありません。

## 修正内容
- Mind9同梱のcanvasサンプルに準拠した構造体型、キャンバス生成、図形ID取得、色設定、描画の記法へ修正しました。
- 未定義だった擬似的な乱数、粒子構造体操作、タイマー処理、描画API呼び出しを除去しました。
- `firework.src` はMind9コンパイラが要求するSJIS/CP932形式で保持しています。
- 背景付きキャンバス上に、色と大きさの異なる火花と中心光を描画する構成にしました。

## 参照
生成ルールに従い、`manual-md` フォルダ内の全 `.md` を参照対象として確認し、Mind言語の構造体、処理単語、GUIキャンバス仕様は同梱サンプルとマニュアルの記法に合わせました。

```
アプリ仕様の縛りはゆるめで（実際のところ明示的な指定なし）既存ソースコードのコンパイルエラーの改修が最優先されて、機能自体がだいぶ削られてしまいました。
生成レスポンスの「なお、現在の実装は静的な花火描画です。」とはこういうことだったのかと認識しました。
