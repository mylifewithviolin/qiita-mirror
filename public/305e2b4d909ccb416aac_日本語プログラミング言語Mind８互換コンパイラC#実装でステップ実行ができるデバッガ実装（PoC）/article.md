# はじめに
Mindのランタイム中間コードをC言語以外で走行させる互換ディスパッチャがC#とJavaとZig環境で進行中です[^1][^2][^3]。またそれと対をなすMindソースから中間コードを生成するC#互換コンパイラ（PoC/概念実証版）も実装しています[^4]。とりあえず、C#で実装した互換ディスパッチャと互換コンパイラはDLL(API)として実装されており、変数スタックのステップ毎レポート機能を独自に実装しましたので、その機能を利用するMindコードエディタ・デバッガをC#で実装してみました。


# 日本語プログラミングMind（マインド）とは
プログラミング言語Mind（マインド）は自然な日本語で記述できるスタック指向の軽量中間コードコンパイラ言語です[^5]。単語間の分かち書きが必須であくまで形式言語ですが、逆ポーランド記法[^6]で分かち書きされた日本語単語の語順が自然と日本語の語順となる「自然さ」で書くことができます。実装言語はCまたはTcl/Tk、Mind自身。

# Mindコードエディタ・デバッガ実装案
Mindソースの編集、Mind8 Console互換コンパイラによるコンパイル・実行、ステップ実行中のスタック・変数監視を一体化したアプリケーションを実装します。

## 利用できる既存機能
```text
- コンパイラは `C:\developments\cs14\remind8cs` の `Rmind8.Compiler.Core`。
- `Rmind8Compiler.Compile(source, sourceName, target)` はメモリー上のソースを
　受け取り、MCOイメージまたはソース位置付き診断を返す。エディタ本文を一時ソースファイル
 へ保存せずに渡せる。
- `McoEncoder` によるMCO出力と、ファイル入出力用CLI `rmind8c` がある。
- 対象ABIは、形式バージョン8、ランタイム10、シリアル46、Little Endianのconsole
　プロファイル。
- または `C:\developments\vscode\mind8dispatch` のC#コンソールディスパッチャ。
　旧来のCカーネルや別ABIへ無検証で切り替えない。
```
## 追加する機能

| 項目 | 現状と追加内容 |
|---|---|
| WPF画面 | 本アプリにエディタ、コンソール、デバッガ、エクスプローラを実装する |
| 通常実行 | Coreでコンパイルし、別プロセスのディスパッチャでMCOを実行する |
| デバッグ情報 | ソース位置と命令位置の対応、変数名・型・格納位置等をコンパイラから出力する |
| ステップ実行 | ディスパッチャにロード・停止・再開・単一命令実行・状態取得の制御を追加する |
| スタック監視 | 停止境界でデータスタック／リターンスタックを読み取り専用スナップショットとして取得する |
| 変数監視 | 変数構文・コード生成・シンボル情報・実メモリーの値取得を追加する |

既存ディスパッチャには命令やスタック値を標準エラーへ出すトレースがあるが、これは構造化されたステップ実行APIではない。トレース文字列の解析やUI側の実行模倣ではデバッガを実装しない。

## メニューとコマンド

| メニュー | 項目 | ショートカット案 | 動作 |
|---|---|---|---|
| ファイル | 新規作成／開く／保存／名前を付けて保存／終了 | Ctrl+N／Ctrl+O／Ctrl+S／Ctrl+Shift+S | 文書操作と未保存確認 |
| 編集 | 元に戻す／やり直し／切り取り／コピー／貼り付け／すべて選択 | 標準キー | フォーカス先に応じた操作 |
| 表示 | ソースコードエディタ／実行コンソール | なし | 右タブの選択 |
| 表示 | エクスプローラ更新 | なし | 起動フォルダ配下の再列挙 |
| ビルド | コンパイル | Ctrl+Shift+B | 現在の本文をコンパイルし、診断・生成結果を表示。実行しない |
| ビルド | コンパイルして実行 | Ctrl+F5 | 現在の本文をコンパイルし、成功したMCOを通常実行 |
| デバッグ | デバッグ開始／続行 | F5 | 未開始ならデバッグ用コンパイルと初期停止、停止中なら続行 |
| デバッグ | 一時停止 | なし | 実行中に次の安全な命令境界で停止要求 |
| デバッグ | ソースステップ実行 | F10 | 次のソース停止位置まで進め、スタックと変数を更新 |
| デバッグ | 命令ステップ実行 | F11 | Mコード1命令を実行し、状態を更新 |
| デバッグ | 停止 | Shift+F5 | 通常実行／デバッグ実行を終了 |
| 表示 | コンソールのクリア | なし | 表示済み出力のみ消去。実行状態には影響しない |

## プロジェクト構成

```text
remind8code\
  docs\
    テキストエディタアプリケーション実装プラン.md
  src\
    Remind8Code\                 WPF、Views、ViewModels、Models、Services
    Remind8Code.ExecutionHost\    ディスパッチャのプロセスホスト
    Remind8Code.ExecutionProtocol\ 制御要求・応答・スナップショットの型
  tests\
    Remind8Code.Tests\            文書・コマンド・状態遷移・連携テスト
    fixtures\                    検証用ソース・期待出力・期待状態
```

Coreおよびディスパッチャは複製せず、Phase 0では既存配置へのプロジェクト参照とビルド手順を明示します。配布時には必要な依存物を同梱し、開発機の絶対パスなしで起動できる形にします。制御プロトコルの型はUI・ワーカーで共有し、コンパイラCoreには依存させません。

※開発中の仕様により、予告なく変更される場合があります。
