# Windows95ってなに？

いまから３０年前、Windows95というOS（オペレーティングシステム）が出荷されたときに、ご家庭にもパソコンが爆発的に浸透して、インターネット閲覧の環境として広く使われるようになりました。

またビジネスの現場でも、WindowsNT4.0Serverがネットワークサーバーとして使われるようになり、サーバーもWindows、クライアントもWindows（95またはそのデスクトップルックスを搭載したNT4.0ワークステーション）というWindows一強の環境が日本でも一般的となりました。

しかし、昨今のスマートフォンやタブレットによるパーソナルコンピューティング環境のダウンサイジングにより、いまはパソコンをお使いにならずネットを探索閲覧されている方も多いかと存じます。
 

それゆえ、こんにち「Windows95ってなに？」って方も少なくないかと思います。そこで本記事ではみなさまへのご紹介をかねて（できるのはそれだけなのでわたし目線での）Windowsの歴史を振り返ってみます。

  
 
# 今年はWindows生誕40周年

そのWindowsの最初のバージョンはいまから４０年前の１９８５年に登場していたことを知るひとは少ないかもしれません。

この記事では、それぞれのバージョンのメインストリームのWindowsの感想について、つらつらと述べていきたいと思います。本来はデスクトップのスクショなどを載せたいところですが、テキスト中心の記事となりますことご容赦ください。

 
# Windowsのクライアントを中心とした各バージョンの感想(サーバーも軽く触れます)
 

## Windows1.0　1985年
 
パソコンの周辺機器の開発現場にいたわたしは、実験室のパソコンにWindows1.0が動いているのを見たことがあります。それがPC98シリーズだったのかは記憶にありません。このころのパソコンは高額で自費で買うようになるのはもう少し先でした。


このころ存在していたパソコンは下記のような感じでした。

PC-9801VM 1985年 16bit NEC V30 (8086上位互換) 8M/10MHz
FM-16βFD 1984年 16bit 80186 8MHz RAM 512KB
Macintosh 128K 1984年 MC68000 7.8MHz RAM 128KB
 

Appleのマック登場の１年後にはGUI（グラフィカルユーザーインターフェース）のWindows1.0が登場していたことになりますが、当初のWindows1.0のルックスはかなりチープだったと記憶しています。

そのころのOS（オペレーティングシステム）の主流はMS-DOSで、後のバージョンのDOSver.5に搭載されたDOSシェルというCUIメニューにWindows1.0のルックスが似ていた記憶があります。（あくまでわたしの記憶です。）
 

## Windows2.0　1987年　(2.11) 
 
Windows２．０の出荷年は1987年ですが、わたしが買ったことがあるのはNEC-PC9800シリーズ用のWindows2.11ですので、その出荷年は米国時より少しあとかもしれません。また実際に買ったのは次のWindows3.0が既に存在していたころです。

当時、東京に在住していたわたしは、秋葉原のパソコンショップでWindows2.11のパッケージケースを発見し、いくらだったか記憶はないのですが衝動買いした記憶があります。後継バージョンが出た後ではあったので、定価より安くなっていた記憶があります。

  
1987年当時のパソコンの雰囲気は下記の雰囲気でした。

PC-9801RA 1988年 32/16bit 80386 16MHz / V30 8MHz RAM 1.6MB
PC-286 1987年 16bit 80286 10MHz
Macintosh SE 1987年 MC68000 7.8MHz RAM 1MB

わたしが最初に買ったパソコンはエプソンのPC-286シリーズのどれかです。Windows2.11もそれにインストールしようとして買ったものでした。
 
 

## Windows3.0　1990年　（3.1）1992年　

わたしが最初に仕事で使ったWindowsがWindows3.1でした。

当時、IntelBASICで数値計算シミュレーションのプログラムを書いていたわたしは、会社に提案して数式を定義すればシミュレーション実装を展開して計算してくれるMathematicaの祖先バージョン2.1あたりを導入しました。


それ（Mathematica）の動く環境がWindows3.1でした。


Windows3.1はいまのWindowsに似ているといえば似ていますが、まだパソコンのグラフィックは非力でしたので、けっこうあっさりしていたルックスです。
 
また、MS-DOSがまず起動して、その後Windowsが起動してくるつくりでした。
 

## Windows95　1995年
 

今年でWindows95生誕３０周年です。 いまから思えば超軽量のグラフィカルユーザーインターフェース（GUI）のOSでした。

わたしがシステムエンジニアに職種変更してから仕事で開発したクラインアント／サーバーシステムのクライアントアプリケーション開発のプラットフォームとして最初のOSでした。


そのころのサーバーはWindowsNT4.0Serverで、データベースはSQLServerの祖先6.xとかが動いていました。

個人的には当時としては超コンパクトPCであったIBMのPC-110（初期インストールOSはPC-DOS）にWindows95をインストールして遊んだ記憶があります。


## Windows98　1998年
 

いまから思えばかなり先進的な、アクティブデスクトップというインターネットに接続されたデスクトップ環境が実装されていました。

まだ当時のパソコンやインターネット帯域は非力で、だいぶ重たいので通常切っていた気がします。

インターネットブラウザとして一世を風靡したインターネットエクスプローラ（IE）が出荷構成として標準搭載となったのがこのバージョンでした。

その前のWindows95はオプションパックとかいう無償で配布されたCD-ROＭに入っていました。WindowsNT4.0Server向けのオプションパックも確か存在していて、IIS（Internet Information Server　当時はServiceではなくServerだったような気がします。かなりうろ覚え）もここからインストールしていたと思われます。（あくまでわたしの記憶です。）
 

## WindowsMe　2000年

Windowsの当時の2系統のひとつ、Windows3.0/3.1/95/98の流れを汲む最後のバージョン。

MSDOSの16ビット構造を少し残していたため、ビジネスクライアントOSとしては不安定といわれていたため、このバージョンを最後のこの系列のWindowsは終息しました。

 Meを個人的に買うことはなく、仕事でクライアント環境の検証OSの１つとして使っていた記憶があります。

## Windows2000　2000年

Windowsの当時の2系統のひとつ、WindowsNTシリーズの3.5/4.0のサーバーOSとカーネルを共有するクライアントOSを消費者向けシリーズとも統合した最初のバージョンのWindowsです。

このころから、IT製品名のバージョンに西暦年を冠することがはやりだしました。Windowsのサーバー製品は西暦年バージョンを継続していきます。 

Windows 2000 Server
Windows 2000 AdvancedServer
とか。IIS５を搭載。

## WindowsXp　2001年
 
ビジネス用Windowsクライアントの最初の安定版で、後継のVistaが不評だったため長期にわたり使われ続けました。

草原のデスクトップイメージが印象的。

個人的にも自宅のパソコンのOSはWindowsXpになりました。現在は実機が残っていませんが、Windows7上の仮想Xpが残っています。
 

Xpは非常に長期にわたって使われたため、マイクロソフトはWindos7上にXpモードという仮想環境を用意して、Windos7への移行を促しました。

2003年にはIIS６を搭載したサーバー版
Windows Server 2003 が出荷され、安定版として稼働しました。
2005年には
Windows Server 2003 R2 が出荷。

## WindowsVista　2006年
 

WindowsVistaは内部的にはだいぶ革新のあったバージョンです。デスクトップのルックスもXpよりずっと美しくなりました。
 
しかし、ユーザーアカウントコントロール（UAC）の既定レベルが厳しいため、このダイアログが頻出して消費者ユーザーには不評のため、あまり売れなかったバージョンでもあります。
 
わたしの個人環境でWindowsVistaはノートパソコンとしてまだ実機が残っています。

対応するWindowsServerは下記のとおり。
Windows Server 2008  2008年

## Windows7　2009年
 
ビジネス用WindowsクライアントのXpに続く次の安定版で、後継の8/8.1が不評だったためWindows７も長期にわたり使われ続けました。

WindowsXpからの移行を促すため、Xpモードという仮想環境を設けて、互換性のないアプリはWindowXp仮想マシン上で動作するようにしました。（アプリのウィンドウだけXpモードで動作するモードもご用意）

わたしの自宅のパソコンにも２つのデスクトップに環境が残っています。

対応するWindowsServerは下記のとおり。 
Windows Server 2008 R2　2009年

## Windows8　2012年　(8.1)　2013年
 

Windows8はわたし的にはインテルはいっていない初めてのPCでした。

インテルはいっているPCでのWindows8も一般的にはもちろん存在するのですが、わたしがもっているのはNEC Lavieのノートパソコンで、ディスプレイパネルがキーボードの底まで折り返って、いちおうタブレットみたいにも使えるというやつです。 

Windows8.1にアップデートして、実機として残っているのはこれ１台です。

対応するWindowsServerは下記のとおり。
Windows Server 2012　   2012年
Windows Server 2012 R2　2013年

## Windows10　2015年

今年はWindows１０生誕１０周年です。もうそんなになるのですね。

Windows10が出荷されたころは、最後のWindowsという風にマイクロソフトはプロモーションしていて、OSはサービス化されるかのような勢いでしたが、Windows11の出荷と移行要件の厳格化により、そのコンセプトはなかったことになりました。

実機としては自宅でノートPCが１台、タブレットが１台まだ稼働しています。

これ以降のWindowsServerは下記のとおり。 
Windows Server 2016　2016年
Windows Server 2019　2018年

## Windows11　2021年

デスクトップのデフォルトのイメージ画像のブルーの薔薇の造花が印象的。

内部バージョンは１０なので、もしかしてWindows10出荷時のプロモーションを気にしているのかもしれません。いまのことろ最後のバージョンは１０を維持。

これ以降のWindowsServerは下記のとおり。
Windows Server 2022　2021年
Windows Server 2025　2024年

いまこの記事はWindows11で書いています。
