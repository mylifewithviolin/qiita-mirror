# この小技に関連するMind言語マニュアル
この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載があります。
３ 制御構文
└ここから～繰り返す

>繰り返し処理の最も標準的なものである。次のような構文で用いる。（太字が構文の基本要素）
>
>構文＝　**ここから**
　　　　　　　　・・・・・・・・・・・・
　　　　　　　　・・・・・・・・・・・・
　　　　　　　　＜条件値発生処理＞
　　　　　　　　　　　　ならば　**打ち切り**
　　　　　　　　　　　　つぎに
　　　　　 **繰り返し**
>
>　この構文は基本的に永久ループであり、打ち切りたいときに「打ち切り」を実行することで、明に打ち切る方法をとっている。この方法の利点は、打ち切り条件が複数になった場合でもまったく形を変える必要がないこと、打ち切りの判定がループの最初にあっても終りにあっても、形は同じであるという点である。

# 小技の解説
「打ち切り」はループの処理を途中で脱出させる単語です。他のプログラミング言語での「break」文に相当します。

「break」には、「破損」「休憩」「中断」といった意味がありますが、プログラミング言語によってはループから脱出以外でもいくかの条件分岐構文からの脱出につかわれます。「break」は仕事や勉強などの合間に作業を中断して休憩する場合に使うことができますので、恐らくこの文脈での意味と推察されます。Mind的にはループ構文中でのこれを「打ち切る」と表記しています。

# Mindプログラムソース

```mind:breakloop.src

表示する前にループを途中で脱出するとは （・　→　・）
        打ち切り条件は　変数

    打ち切り条件に　０を　入れ
    ここから
        打ち切り条件が　１０　以上
        ならば　打ち切り
        つぎに
        打ち切り条件を　数値表示し　改行し
        打ち切り条件を　一つ増加し
    繰り返す。

表示した後にループを途中で脱出するとは （・　→　・）
        打ち切り条件は　変数

    打ち切り条件に　０を　入れ
    ここから
        打ち切り条件を　数値表示し　改行し
        打ち切り条件が　１０　以上
        ならば　打ち切り
        つぎに
        打ち切り条件を　一つ増加し
    繰り返す。

メインとは （・　→　・）
    「表示する前にループを途中で脱出」と　一行表示し
    表示する前にループを途中で脱出し
    「表示した後にループを途中で脱出」と　一行表示し
    表示した後にループを途中で脱出すること。
```

打ち切り構文が処理の手前に来るか後に来るかの違いのサンプルです。
「表示する前にループを途中で脱出」は打ち切り構文が処理の手前。
「表示した後にループを途中で脱出」は打ち切り構文が処理の後。
