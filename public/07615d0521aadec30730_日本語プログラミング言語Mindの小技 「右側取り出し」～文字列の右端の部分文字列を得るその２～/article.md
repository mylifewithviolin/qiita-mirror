# はじめに
日本語プログラミング言語Mindの小技「右側取り出し」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# この小技に関連するMind言語マニュアル

この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載があります。
７ 文字列操作
└文字列の操作
　└文字列の左右端の部分文字列を得る


>構文＝＜文字列＞から　＜文字数＞だけ　右側取り出し　　　→　＜文字列＞
>
>　「取り出し」、「右側取り出し」は、指定する文字列の左端または右端から指定文字数だけ参照する機能である。
　文字数は論理文字数として解釈される。つまり、これはバイト数ではなく、論理的な正しい文字数（漢字は ２バイトを１文字として数える）である。
　指定した文字数に足りない場合には、ある分だけが返される（元から空列の場合には空列が返される）。


本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。


# 対応バージョン
■Mind７　■Mind８　■Mind９
■Windows版　□Linux版

# 小技の解説
Mindの小技「右側取り出し」は、Mindの文字列切り出し機能の１つです。「右側取り出し」は文字列の右端から部分文字列を切り出します。

他のプログラミング言語の文字列切り出し機能では「subString」などがありますが、Mindのこの機能はそれに近い機能のライブラリとなります。

Mindの別の文字列切り出し機能の「右側切り出し」***1**は、切り出し元の文字列実体変数からも切り出された文字列は除去されますが、「右側取り出し」はそのような作用はないため、処理対象の文字列は、文字列リテラル、文字列定数、文字列情報変数、文字列実体変数のどれでも可となります。

「右側切り出し」の記事の中でマニュアルから引用している下記の説明文の

>　「切り出し」「右側切り出し」は、前半の２つとよく似ているが、

「前半の２つ」とはこの文字列操作単語「右側取り出し」（と「取り出し」***2**）のことです。


# Mindプログラムソース
```mind:takeoutstrings.src
取り出し元文字列は　文字列定数　「ＭｉｎｄなでしこＣＣ＋＋Ｃ＃ＪａｖａTypescript」。
取り出し文字数は　定数配列　１０，４，２，３，１，４，４。　
取り出し単語帳は　７つの　文字列実体　長さ　１０。


取り出し元文字列を一行表示とは　（・　→　・）
    「取り出し元文字列：」を　表示し　
    取り出し元文字列を ダブルクオートで囲んで表示し　改行すること。

単語を一行表示とは　（文字列　→　・）
    「取り出し単語：」を　表示し　一行表示すること。

メインとは　（・　→　・）
        取り出し単語は　文字列
        前回合計文字数は　変数
        前回文字数は　変数
        合計文字数は　変数

    取り出し元文字列を一行表示して　改行し、「文字列右側取り出しを開始」を　一行表示し、
    前回合計文字数に　０を　入れ
    前回文字数に　０を　入れ

    取り出し単語帳の　要素数で　回数指定し
        取り出し文字数（回数）と　前回合計文字数を　加えて　合計文字数に　入れ
        取り出し元文字列から　合計文字数を 右側取り出して　取り出し単語に　入れ
        取り出し単語で　単語を一行表示し
        取り出し元文字列を一行表示し
        
        取り出し単語を 取り出し文字数（回数）で　取り出して　取り出し単語に　入れ
        取り出し単語で　単語を一行表示し、

        取り出し単語帳（回数）に　取り出し単語を　入れ
        前回文字数に　取り出し文字数（回数）を　入れ
        前回合計文字数に　合計文字数を　入れ
    繰り返してから、

    改行し　「単語取り出し結果を表示」を　一行表示し、
    
    取り出し単語帳の　要素数で　回数指定し
        取り出し単語帳（回数）で　単語を一行表示し、
    繰り返すこと。
```
繰り返し切り出すときに文字の位置範囲（何文字目から何文字目まで）を指定しなくてもよいので便利です。切り出す文字数は反復回数で変化するので、「事例」を使っています。
