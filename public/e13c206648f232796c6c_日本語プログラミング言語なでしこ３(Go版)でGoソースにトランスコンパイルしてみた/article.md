
### コンパイル実行
とりあえずそのままの状態でなでしこ３(Go版)のCLIでコンパイル実行してみます。
PowershellではなくコマンドプロンプトのVSCodeターミナルです。

```cmd
C:\developments\vscode\gonako>gonako count3.nako
[文法エラー]count3.nako(11行目): 単語『countMax』への代入文で計算式に書き間違いがあります。

C:\developments\vscode\gonako>
```
11行目が構文エラーとなりました。11行目は下記のヶ所ですので、コマンドライン[3]の配列の記述方法とかが変わったのかもしれません。
```nako:count3.nako
　    countMax=コマンドライン[3] //を整数変換
```
ここをコメントアウトしてみます。
```nako:count3.nako
　   ※ countMax=コマンドライン[3] //を整数変換
```

### 修正コードでコンパイル実行
もう一度コンパイル実行すると．．．

# なでしこ３のソースをGoソースにトランスコンパイルしてみる

なでしこ３(Go版)にはGo言語ソースコードへのトランスコンパイル機能がついているみたいで、非常に興味がございます。

```cmd
C:\developments\vscode\gonako>gonako
gonako - なでしこ3 Go言語版

使い方:
　～略～
  gonako gengo <ファイル> [オプション] Goソースに変換する（段階10・gogen）
```

### Goソースにトランスコンパイル実行

このオプションの意味するところはわかっていないのですが、前回記事では無謀にもいきなりなでしこ１ソースをトランスコンパイルしようとしてエラーになってましたが、本記事では上記のとおり動作するなでしこ３相当ソースがご用意できましたので、さっそくトランスコンパイルしてみます。

```cmd
C:\developments\vscode\gonako>gonako gengo count3.nako
count3.go を作りました
ビルドするには、count3.go と同じ場所に go.mod を用意し、以下を requireとreplaceに書いてください:
  require github.com/kujirahand/nadesiko3go v0.0.0
  replace github.com/kujirahand/nadesiko3go => C:\developments\vscode\gonako

C:\developments\vscode\gonako>
```

動きました:tada::tada:トランスコンパイル成功みたいです:tada:

### 生成されたGoソースをGoコンパイラでビルドしてみる
Goソースが生成されたときのコメント
>ビルドするには、count3.go と同じ場所に go.mod を用意し、以下を requireとreplaceに書いてください:
  require github.com/kujirahand/nadesiko3go v0.0.0
  replace github.com/kujirahand/nadesiko3go => ～略～
  
は、とりあえず無視して無謀にもそのままGoコンパイラでビルドしてみます。
```cmd
C:\developments\vscode\gonako>go version
go version go1.19.5 windows/amd64
```
だいぶ前に入れたやつのパスが通っていました。

```cmd
C:\developments\vscode\gonako>go build count3.go
```
