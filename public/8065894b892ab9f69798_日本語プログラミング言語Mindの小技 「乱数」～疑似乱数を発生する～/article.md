# はじめに
日本語プログラミング言語Mindの小技「乱数」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# 対応バージョン
本機能（本記事）は、下記のバージョンに対応しています。Mind８は本記事では特に検証を行っておりませんが、Mind８をダウンロードしたタイミングによってはsrclibフォルダに格納されていた場合があります。

□Mind７　□Mind８　■Mind９
■Windows版　□Linux版

# この小技に関連するMind言語マニュアル
この小技に関連する記述はMindプログラミングマニュアルに記載はありません。mind9のsrclibフォルダの下記のテキストファイル
srclib\cransu-manual.txt
が該当します。

>■乱数を得る
>
>　　－－－－－－－－－－－－－－－－－－－－－－－－－
　　＜最小値＞から　＜最大値＞の　乱数を得る　→　乱数
>
>　　　　　　注：最小値、最大値、乱数のいずれも、
　　　　　　　　ゼロ以上の32bit整数
　　－－－－－－－－－－－－－－－－－－－－－－－－－
>
>　指定した範囲の乱数を得ます。返される値はゼロ以上の32bit整数です。
　最小値と最大値が逆転している、または同じ値の場合は動作は保証され
ません。

# 小技の解説
Mindで記述されたソースコード提供の疑似乱数を発生する簡易ライブラリです。

# Mindプログラムソース

## Mindライブラリのインクルード
乱数ライブラリをインクルードするよう下記のように記述します。
```mind:testrandom.src
"../srclib/cransu.src"を　コンパイル。
```

## お題のテスト用コード
お題のテスト用コードは下記のとおりです。
```mind:testrandom.src
"..\srclib\cransu.src"を	コンパイル。

メインとは
	乱数初期化し
	日時で乱数の種を設定し

    ２０で　回数指定し
        １から　２１４７４８３６４７の　乱数を得て　数値表示し　改行し
    繰り返すこと。

```
２０個の乱数を生成してみます。最大値の方は３２ビット整数の上限値を与えてみました。

「日時で乱数の種を設定」は現在の日付の時刻（精度は１秒）を使って乱数の種を設定します。「乱数初期化」の後で実行します。
