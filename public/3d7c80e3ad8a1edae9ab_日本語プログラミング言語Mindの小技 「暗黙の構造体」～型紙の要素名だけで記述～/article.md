# はじめに
日本語プログラミング言語Mindの小技「暗黙の構造体」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# この小技に関連するMind言語マニュアル

この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載があります。
１０ 構造体・型紙
└型紙
　└暗黙の構造体（型紙との連携で）

>暗黙の構造体は次のように定義する。
構文　＝　＜構造体名＞は　暗黙の構造体　＜型紙名＞。
>
> 上記のように、型紙を適用した構造体定義と似ている。この定義をおこなうと、いま定義した構造体が、引用した型紙と結びついた暗黙の構造体として認識され、型紙要素を単独で書いた場合に、強制的にその構造体を親構造体として扱うようになる。


本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。

# 対応バージョン
■Mind７　■Mind８　■Mind９
■Windows版　□Linux版

# 小技の解説
この記事の取り扱う「暗黙の構造体」は「型紙」を使って宣言することで構造体名を介さず単独の変数名のように記述できるようにする特殊な宣言構文です。

「型紙」はMindの構造体定義においてインスタンス生成（メモリ上の実体確保）を除いた型情報の定義のみをすることを意味する機能です。Mindの言語仕様の用語としての「構造体」はインスタンス生成がセットになっている機能を意味しますので他のプログラミング言語ご経験者にとっては注意が必要です。


# Mindプログラムソース

```mind:implicitstructure.src
結果セット型は　型紙
        言語IDは　変数
        言語名は　文字列実体　長さ　200
        公開年は　変数
        よみがなは　文字列実体　長さ　200
    行データは　言語IDと　言語名と　公開年と　よみがな
    全体は
　　    4行の　行データ。

結果セットは　構造体　結果セット型。
結果セット暗黙は　暗黙の構造体　結果セット型。

結果セット初期化とは　（・　→　・）
    行データの　要素数で　回数指定し
        結果セットの　言語ID(回数)に 回数を　入れ
    繰り返す
    結果セットの　言語名(1)に 「Mind version 1」を　入れ
    結果セットの　言語名(2)に 「Mind version 7」を　入れ
    結果セットの　言語名(3)に 「Mind version 8」を　入れ
    結果セットの　言語名(4)に 「Mind version 9β」を　入れ
    結果セットの　公開年(1)に 1985を　入れ
    結果セットの　公開年(2)に 1997を　入れ
    結果セットの　公開年(3)に 2017を　入れ
    結果セットの　公開年(4)に 2025を　入れ
    結果セットの　よみがな(1)に 「まいんどばーじょんいち」を　入れ
    結果セットの　よみがな(2)に 「まいんどばーじょんなな」を　入れ
    結果セットの　よみがな(3)に 「まいんどばーじょんはち」を　入れ
    結果セットの　よみがな(4)に 「まいんどばーじょんきゅうべーた」を　入れること。

結果セット暗黙の初期化とは　（・　→　・）
    行データの　要素数で　回数指定し
        言語ID(回数)に 回数を　入れ
    繰り返す
    言語名(1)に 「Mind version 1」を　入れ
    言語名(2)に 「Mind version 7」を　入れ
    言語名(3)に 「Mind version 8」を　入れ
    言語名(4)に 「Mind version 9」を　入れ
    公開年(1)に 1985を　入れ
    公開年(2)に 1997を　入れ
    公開年(3)に 2017を　入れ
    公開年(4)に 2026を　入れ
    よみがな(1)に 「まいんどばーじょんいち」を　入れ
    よみがな(2)に 「まいんどばーじょんなな」を　入れ
    よみがな(3)に 「まいんどばーじょんはち」を　入れ
    よみがな(4)に 「まいんどばーじょんきゅう」を　入れること。

結果セット出力とは　（・　→　・）
    行データの　要素数で　回数指定し
        結果セットの　言語ID(回数)を　数値表示し　「|」を　表示し
        結果セットの　言語名(回数)を　表示し　「|」を　表示し
        結果セットの　公開年(回数)を　数値表示し　「年|」を　表示し
        結果セットの　よみがな(回数)を　表示し　「|」を　表示し　改行し
    繰り返す。

結果セット暗黙の出力とは　（・　→　・）
    行データの　要素数で　回数指定し
        言語ID(回数)を　数値表示し　「|」を　表示し
        言語名(回数)を　表示し　「|」を　表示し
        公開年(回数)を　数値表示し　「年|」を　表示し
        よみがな(回数)を　表示し　「|」を　表示し　改行し
    繰り返す。

メインとは　（・　→　・）
    結果セット初期化し
    結果セット暗黙の初期化し
    結果セット出力し
    改行し
    結果セット暗黙の出力すること。
```

「結果セット暗黙の初期化」と「結果セット暗黙の出力」の定義では、暗黙の構造体のメンバ変数配列が構造体名の装飾なしで記述されています。
