# はじめに
日本語プログラミング言語Mindの小技「指定範囲をソート」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# 対応バージョン

# 小技の解説
Mindで記述されたソースコード提供のクイックソートライブラリです。ソートキーの読み出し、レコードの読み出し、レコードの書き込みをユーザが用意した処理単語をライブラリの側からコールバックすることで高速処理を実現します。

# Mindプログラムソース
お題のサンプルソースコードを説明いたします。

## Mindライブラリのインクルード
クイックソートライブラリをインクルードするよう下記のように記述します。
```mind:mquicksort.src
最大ソートデータ数は　　　数値　　   １００００個。　※1万件ソート可能
ソートキー最大長は　　　　数値　　　　２５６桁。　※256桁の文字列を比較できる

"../srclib/qsort.src"を　コンパイル。
```
## ソート処理実行用コード
ソートを処理するためにはライブラリをインクルードした後、若干の定型コードを書く必要があります。
```mind:mquicksort.src

	ローカル。

ソートキーは　　　最大ソートデータ数の　文字列。
対象行は　　　　　最大ソートデータ数の　文字列。
対象数は　　　　　変数。

ソートキー参照処理とは　（番号　→　値）
	ソートキー（スタック）を　返すこと。

レコード参照処理とは　（番号　→　レコード）
	対象行（スタック）を　返すこと。

レコード格納処理とは　（レコード、番号　→　・）
	対象行（スタック）に　入れること。

ソート処理とは　（・　→　・）
		ソートワークは　構造体情報
	対象数が　１　以下
		ならば　終り
		つぎに
	対象数で　ソートワークを確保し　ソートワークに　入れ
	ソートワークと、
	　ソートキー参照処理の　Ｍコードと、
	　　レコード参照処理の　Ｍコードと、
	　　　レコード格納処理の　Ｍコードと、
	　　　　０と
	　　　　　０と
	　　　　　　１から　対象数と、
		　　　文字列ソートと　昇順で
			　指定範囲をソートし
	ソートワークで　ソートワークを解放すること。

※ここまでがソート処理の賞味記述
```
このあたりはmind9のsampleフォルダの下記のサンプルソースファイル
sample\sortSimple.src
に記述例があります。

「レコード参照処理」がソートキーの読み出しをユーザが用意した処理単語となります。「レコード参照処理」、「レコード格納処理」がそれぞれレコードの読み出し、レコードの書き込みをユーザが用意した処理単語となります。それぞれの処理単語の「Ｍコード」を「指定範囲をソート」の引数スタックに置くことで、ライブラリの側すなわち「指定範囲をソート」内部からこれらの処理単語をコールバックするようにしています。

こちら（sortSimple.src）はファイルからソート対象を読み込む本格的なサンプルですが、本記事ではとりあえずアプリに組み込むための最小限のコードサンプルとしています。また、「データプール」は使用しない構成でのサンプルです。

srclib\qsort-manual.txtからの引用
>”大量の文字列”をMind内部に格納するのに便利なライブラリが別途用意されています。それがデータプール（datapool.src）というソース形式ライブラリです。
　実質的にソートライブラリはデータプールライブラリと一緒に利用することになります（必須でありません）。

## お題のテスト用コード
お題のテスト用コードは下記のとおりです。
```mind:mquicksort.src

	グローバル。

ソート対象は　文字列定数配列
"171"　"182"　"193"　"214"　"155"　"146"　"137"　"128"　"309"　"100"　 "901"　 "802"　 "704"　 "605"　 "511"。

※ソート対象の準備作業記述
データを準備するとは　（・　→　・）
		行は		文字列

	対象数を　クリアし
	ソート対象の　要素数で　回数指定し
		ソート対象（回数）を　行に　入れ
		行が　空列？
		ならば　もう一度　つぎに
		対象数を　一つ増加し
		行を　ソートキー（対象数）に　入れ
		行を　対象行（対象数）に　入れ
	繰り返すこと。

ソート対象を表示するとは　（・　→　・）
	対象数で　回数指定し
		対象行（回数）を　表示し　「　」を　表示し
	繰り返すこと。

メインとは  （・　→　・）
	データを準備し
	「ソート前　」を　表示し　ソート対象を表示し　改行し
	ソート処理し
	「ソート後　」を　表示し　ソート対象を表示し　改行すること。
```
先に述べましたが、本記事はアプリに組み込むための最小限のコードサンプルですので、ソート対象は文字列定数配列から読み込んでいます。

また、前記のライブラリのインクルード文の定数はサンプルどおりの値を宣言しましたが、本記事のソート対象データを並べ替えるだけであるならば、下記の値で動作します。
```mind:mquicksort.src
最大ソートデータ数は　　　数値　　   １５個。　※1万件ソート可能
ソートキー最大長は　　　　数値　　　　３桁。　※256桁の文字列を比較できる
```
