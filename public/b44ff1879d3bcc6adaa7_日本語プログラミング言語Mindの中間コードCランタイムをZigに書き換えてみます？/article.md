# はじめに
Mind8の中間コードディスパッチャ（の一部）をCからC#に書き換えてみるという野望として、Cのディスパッチャ配下の関数配列をC#で実装していましたのがちょうど２年前でした。

https://qiita.com/mylifewithviolin/items/151517f7a57b5b8b97f5

当時の思いとしてはCでランタイムを追加するのって気をつかうのでちょっとたいへんとおもったころでして、たしか固定長小数点型がまだMindにはないらしいということから行き掛かり上実装してみたりして、その流れからMindの中間コードディスパッチャのしくみを認識するにいたり、これってC#で実装できそうという見立てとなりました。

理屈上はJavaでもイケると踏んではいたのですが、大量の中間コード実装の荒海に飲み込まれ沈没してしまっていたという経緯でございます。

いちおうC言語ファンとしては昨今のC言語のセキュリティ上の懸念からいよいよ後継言語に移行しましょかというお話が出ているのは認識していて、日本語プログラミング言語あおいがネィティブにコード生成するとしたらどれがいいですかね、やっぱRustですかねとかMicrosoft Copilotさんと雑談しておりましたら、いまはZigってのもあるよと教えていただいたところでございました。


Zigの概要を認識するにいたり、C言語ヘッダが読み込めちゃうとかC言語移植性が高くて安全とかなので、もしかして速度重視ならこっちかもということで、いちおう枠だけつくってみることにいたしました。

# 使用AI

Windows11アプリケーションのMicrosoft Copilot。昨年末から日本語プログラミング言語あおい Aoi（Re:Mind）の原型を作成してもらった生成AI[^2][^3][^4]。モードは「無料プラン」。
## GitHub Copilot
GitHub CopilotのPro+版。あおい実装[^1]と検証の主担当。スーパバイザとしてMicrosoft Copilotを使いGitHub CopilotのCodeAgent推論量を最小化するプロンプトをCopilotで生成しGitHub CopilotのCodeAgentで実行という工法？を採用しています。

### Mind8ディスパッチャとは　C実装概要.md の一部抜粋

```md
# Mind8ディスパッチャ C実装概要

## 対象と構成

本書は `C:\developments\vscode\mind8kernel` のソースを読み、Mind8ランタイムの
中間コード読込みとディスパッチの構造をまとめたものです。通常カーネルの構成は
`kernel.c` がコンパイル時の設定を定義し、実装本体の `kerbody.c` をインクルードします。
コンパイラ用などの別構成は `compker.c` などから同じ本体を異なる設定で組み立てます。
```

これはごく一部のさわりですが、デバッグ実行しながらひっしこいて内容把握した実装をGitHub Copilotはおよそ30分程度の読解で詳細に認識した模様。（別件のC#書き換えからの引用です。）
