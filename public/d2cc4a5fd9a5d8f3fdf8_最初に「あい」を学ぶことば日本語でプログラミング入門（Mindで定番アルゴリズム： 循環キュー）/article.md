# はじめに
本記事シリーズは母国語のプログラミング言語が存在するという文化的価値をアピールするためのもので、プログラミング一般の入門を意図するものではありません。とはいっても題材としては定番アルゴリズムのいくつかを疑似言語ではなくコンパイル・実行可能なプログラミング言語の日本語で書いてみようというたてつけとなります。

## Mind（マインド）
プログラミング言語Mind（マインド）は自然な日本語で記述できるスタック指向の軽量中間コードコンパイラ言語です。ただし単語間の分かち書きが必須であくまで形式言語です。逆ポーランド記法[^1]の範囲で分かち書きされた日本語単語の語順が自然と日本語の語順となるという意味の「自然さ」で書くことができ、独自の軽量中間コードのランタイム実行で非常に高速です。実装言語はCまたはMind。初版の登場は1985年で2025年は生誕４０周年となりました。

# 定番アルゴリズム：循環キューとは
アルゴリズムは、問題を解決するための手順や計算方法を意味します。アルゴリズムにはいくつかの定番ロジックが存在します。

  ここではその中のひとつ「循環キュー」を扱ってみます。「循環キュー」（またはただの「キュー」）は先に入れた要素から順に取り出すデータ構造とロジックです。
  
この「キュー」には大きくわけて「線形キュー」と「循環キュー」の２つがあります。
「循環キュー」は空いたキューを使いまわしていきますが、「線形キュー」は使いまわさないシンプルなロジックです。今回は「循環キュー」を扱います。

「線形キュー」は、こちらの記事をご参照ください。

https://qiita.com/mylifewithviolin/items/8be7f45cd5a1e302e171

# お題のソースコード

下図のようなインデックス構造を構築します。循環の様子をわかりやすくするため、キューの最大深さは５とします。

```
index: 1   2   3   4   5   ...
```
ではなく
```
index: 1   2   3   4   5 
```
ということになります。

Mindの配列の基数は１です。基数０の配列を使った一般的なプログラミング言語の実装とはインデックスの扱いが異なる点にご留意ください。


まず、初期状態ではheadが１を指していて、tailは1となっています。
```
初期状態
index: 1   2   3   4   5 
       ↑
     head (取出位置)
　　　  ↑
　　　tail (挿入位置)
```
線形キューではtailの初期値は0でしたが循環キューでは1です。（線形キューでもtailの初期値1で実装はできます。）
```
３つデータを挿入（tailが４へ移動）
index: 1   2   3   4   5 
       ↑
     head (取出位置)
  　　　　　　　　　 ↑
　　　　　　　　tail (挿入位置)
```
３つデータを挿入すると、tailが４に移動します。このときキューサイズは３に増加します。ここで「キューサイズ」といっているのは値の入っているキューの数を意味します。

１つデータを取出すると、
```
１つデータを取出（headが2へ移動）
index: 1   2   3   4   5  
           ↑
         head (取出位置)
  　　　　　　　　　 ↑
　　　　　　　　tail (挿入位置)
```
headが１のデータを返し、headは２へ移動します。キューサイズは１つ減少し２になります。

もう１つデータを取出すると、
```
もう１つデータを取出（headが3へ移動）
index: 1   2   3   4   5  
    　　       ↑
         head (取出位置)
  　　　　　　　　　 ↑
　　　　　　　　tail (挿入位置)
```
headが２のデータを返し、headは３へ移動します。キューサイズは１つ減少し１になります。

もう１つデータを取出すると、
```
もう１つデータを取出（headが4へ移動）
index: 1   2   3   4   5 
    　　       　　 ↑
         head (取出位置)
  　　　　　　　　　 ↑
　　　　　　　　tail (挿入位置)
```
headが３のデータを返し、headは４へ移動します。キューサイズは１つ減少し０になります。このとき取出位置と挿入位置が同じポジションとなりますが、初期状態が右に３つ移動しているととらえることができます。

ここで再度３つデータを挿入します。ここからが循環の説明です。

```
３つデータを挿入（tailが２へ移動）
index: 1   2   3   4   5  
    　　       　　 ↑
         head (取出位置)
  　　　　　　  ↑
　　　　　　　　tail (挿入位置)
```
再度３つデータを挿入すると、tailが２に移動します。このときキューサイズは３に増加します。

３つデータを挿入の１回目で　tailが４に挿入してtailが５に移動
３つデータを挿入の２回目で　tailが５に挿入してtailが１に移動
３つデータを挿入の３回目で　tailが１に挿入してtailが２に移動


データを格納する入れ物は数値の場合は１次元配列の変数とします。インデックスの位置を先頭と尻尾で管理する変数も設けます。キューサイズは別の変数で管理してデータの挿入の都度一つ増加、取り出しの都度一つ減少させます。


下記がソースコード全文となります。今回は他のロジック実装から利用しやすいようライブラリとして定義して、テスト用のメイン部分を別ソースとしました。

## ライブラリ

```mind:queuecirculer.src
キュー深さ最大は　定数　５。

キュー値は　キュー深さ最大の　変数。
キュー先頭は　変数。
キュー尻尾は　変数。
キューサイズは　変数。

キューを初期化するとは （・　→　・）　
    キュー先頭を　セットし
    キュー尻尾を　セットし　※線形キューはクリア
    キューサイズを　クリアすること。
    
キューに入れるとは （キュー値　→　・）　

    キューサイズが　キュー深さ最大に　等しい　
    ならば　「キューがオーバーフローしました。」で　重大エラー　つぎに　

   （キュー値を）　キュー値（キュー尻尾）に　入れ
    キュー尻尾を　一つ増加し

    ※キュー尻尾を循環させる
    キュー尻尾が　キュー深さ最大より　大きい　ならば　キュー尻尾を　セットし　つぎに
    キューサイズを　一つ増加すること。

キューから出すとは （・　→　先頭キュー値）　

    キューサイズが　０に　等しい　
    ならば　「キューは空です。」で　重大エラー　つぎに

    キュー値（キュー先頭）を　返し　（→　先頭キュー値）
    キュー先頭を　一つ増加し

    ※キュー先頭を循環させる
    キュー先頭が　キュー深さ最大より　大きい　ならば　キュー先頭を　セットし　つぎに
    キューサイズを　一つ減少すること。

キューは空？とは （・　→　真偽）
    キューサイズが　０に　等しい。

キューの内部状態を表示するとは （・　→　・）
    「インデックス：」を　表示し
    キュー深さ最大で　回数指定し
        回数を　数値表示し　「 」を　表示し
    繰り返す
    改行し
    「キューの値　：」を　表示し
    キュー深さ最大で　回数指定し
        キュー値（回数）を　数値表示し　「 」を　表示し
    繰り返し
    改行すること。
```

キュー値配列の「キュー深さ最大」は循環しやすいよう説明文と同じ大きさに確保してあります。取り出す前の挿入回数が「キュー深さ最大」を超えた場合はエラーになります。

この実装でも取り出されたデータ領域（取り出し後のインデックスのキュー値）はクリアされません。新しい値が挿入されるまでは、取り出されたインデックスの値の再取り出しは想定していない一般的な実装です。

キュー値配列の状態を表示する「キューの内部状態を表示する」を設けています。

# おわりに
いかがでしたでしょうか？わたしはわが国に母語によるプログラミング言語が存在することを誇りに思っております。言語は文化。こんにちの日本語のポップスやアニメソングなどが海外でそのまま歌われるような近況を鑑みますと、純然たる技術基盤として超強力な米欧発プログラミング言語勢と存在意義を争うこともなく、日本語の文化として海外でも日本語プログラミング言語の愛される日が来るのやもしれません。



[^1]: 演算子を被演算子の中間に記述する中置記法 1 + 2、前に記述する前置記法（ポーランド記法）+ 1 2、後に記述する後置記法（逆ポーランド記法）1 2 +がある。日本語は１と ２を 足す。
