# はじめに
Mind９βを開発元@killyさんの御厚意により評価用としてご提供いただいておりますので、Mind９βのTclとのインターフェース単語を使い、TclのODBCデータベース操作ライブラリをつかってSQLServer、Mysql、PostgreSQLに対する共通処理単語を実装しておりました。（昨年2025年の7月ごろまで）

今回はかなり思い付きですがMind7のTclとのインターフェース単語をつかってもひょっとして動くんではないかとの興味本位からMind９用に書かれた実装に少し手を加えてMind７環境でも検証します。結果から申し上げますとMind７のTclライブラリにはTclOdbcライブラリが格納されておらず、コンパイルは完走させられましたが、動作は実行できませんでした:relaxed:

# Mind７・９βの言語拡張機能「評価」とは
ご関心があるようでしならば、たいへんお手数ですが、[こちらの記事](https://qiita.com/mylifewithviolin/items/172f91ba20abbb2b3869)をご参照ください。
また、[こちらの記事](https://qiita.com/mylifewithviolin/items/7e8d5ff88eb227a8bbf4)より「評価した値」ではなく、エラー結果を返す「評価した値０」を使用することにより、エラー情報の取得を別途、単語「参照０」を使用して行っています。

# お題のデータべース
SQLServer、Mysql、PostgreSQLでは共通のテーブル構成のデータベースを作成しています。データベース名は「日本語プログラミング言語」です。今回もそれを利用します。今回ソースコード上動かそうとしたのはMySQLです。実は今回の検証の動機としてはMind9が格納しているバージョンのtdbc:odbcではMySQLで謎現象が起きていたので、それをバージョン違いのtdbc:odbcで切り分けられたらいいなというのがありました。
