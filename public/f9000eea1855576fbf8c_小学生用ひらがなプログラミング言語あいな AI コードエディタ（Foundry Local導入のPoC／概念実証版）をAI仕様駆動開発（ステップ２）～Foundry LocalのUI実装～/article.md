# はじめに
この投稿では「小学生用ひらがなプログラミング言語あいな（Aina）」という自作コンパイラ言語のAI コードエディタのPoC／概念実証版を実装していきます。今回はローカルAIのFoundry Localを導入します。実際はモデルも入っていますが、記事内容としてはUI中心となります。

# 「ひらがなプログラミング言語あいな（Aina）」とは
日本語プログラミング言語いずみ（Izumi）の使用可能文字種を「ひらがな」「かたかな」「全角数字」などに制限したバージョンとします。現時点での言語仕様詳細は[こちら](https://qiita.com/mylifewithviolin/items/158f51fbce1ef6bd0ec5)となります。

制御構文の開始シンボルとして、◇、〇、□、・などの全角記号を用い、箇条書きされた日本文としての体裁をあおい（Aoi）いずみ（Izumi）の構文と共有します。小学生の方でも直感的に◇、〇が分岐とループだとわかってもらえそうな気がします:joy:

# 小学生用ひらがなAI コードエディタとは
こどもたちがひらがなでやりたいことをAIチャットゾーンにひらがな入力パネルから入力すると、エディタパネルにひらがなのあいな（Aina）構文が展開されて、それをなんらかのボタン操作でぽちっとやると、なにかがうごく．．．というイメージでございます。

ひらがなプログラミング言語あいな（Aina）は、基本的に静的型付けシステム言語です。中置記法のかっこ書きが基本となります。

関数名やかっこ内の変数名はこどもたちのおもいおもいのひらがなイメージとなりますがこのあたりはAIモデルの日本語能力による感じですかね。慣れている児童が手書きでプログラミング言語構文を書けるようになる場合は、関数名・変数名はずばりこどもたちが考えた内容となります。

```text:natural
まるをいっぱいうごかしたい　でもずっとはや
```
```text:aoi
・かず いっぱい ＝ ０
〇くりかえす
    ◇いっぱい ＝＝ ５ のとき
        □やめる
    ◇ここまで
    □（「〇」）を うつす
    □いっぱい ＝ いっぱい ＋ １ 
〇ここまで
```
※将来的にいずみ（Izumi）やあおい（Aoi）を使っていただくようになると、一般的な静的型付け高級言語との対比がつかみやすいかもという思惑もございます:joy:


# ローカルＡＩはFoundry Local
別件でOllamaを試してみましたところGPUスペックが足らなくて、だいぶ重かったので、今回はFoundry Localで試してみようと考えております。実は現開発環境PCが非常に低スペックでFoundry Localでも荷が重いことが実装検証で判明しております。

## あいな AI コードエディタに組み込むAIサービス比較検討結果
下表はMicrosoft Copilotが出力した比較表を要約したものです。
|番号|比較項目|Ollama|Foundry Local|
|---|---|---|---|
|1|API と SDK|OpenAI互換RESTのみ（SDKなし）|OpenAI互換REST + C# / Python / JS / Rust SDK|
|2|モデル管理|OSSモデルが豊富・`ollama pull`で簡単・Modelfileで軽量カスタム|公式モデル中心・ONNXベースで本格的なカスタム可能・アプリ同梱可能|
|3|性能（GPU/NPU/CPU）|GPU自動利用・NPU非対応・CPU最適化は標準的|GPU/NPU/CPU最適化（ONNX Runtime）・Copilot+ PCで高速|

今回の場合は１のAPIとSDKでC#のSDKがあるらしくC#アプリから内部APIで組み込めるという点でFoundry Localを使ってみることにしました。またモデル管理でアプリ同梱可能がよいかもと仮定。

わたしが選定の際に参考にした現状有姿情報の再掲で、この表の事実性を保証するものではありません。

# あいな AI コードエディタ（FoundaryLocal導入のPoC／概念実証版）の実装構成
## docs\あいなAIテキストエディタ実装FoundaryLocal.md　一部抜粋
### Foundry Local 連携方式
Foundry Local SDK for C#（アプリへ組み込み、利用者側にCLIの別途導入を要求しない方式）を使い、**同一プロセス内でネイティブのチャット補完API**を呼ぶ。
```text
ChatPaneView
   ↓
ChatViewModel
   ↓
ILocalChatService（アプリ側の契約）
   ↓
FoundryLocalChatService
   ↓
Foundry Local SDK（Microsoft.AI.Foundry.Local 系）
   ↓
ローカルモデル（ONNX。CPU / GPU / NPU）
```
今回の実装検証環境のローカルモデルはCPU演算のみ。これがけっこう厳しい感じ。HDD空き容量の関係で大きいモデルは選択できなかったです。

### 画面構成

右ペインを「コンソール／エディタ／AIチャット」の縦3段にします。チャットゾーンの構成はOllama版を踏襲し、エディタの下段に置く。各段は`GridSplitter`で高さを調整でき、チャットは開閉できます（閉じたときエディタが広がる）。

```text
┌──────────────────────────────────────────────────────────────┐
│ ふぁいる   へんしゅう   ひょうじ   えーあい                   │
├───────────────────────┬──────────────────────────────────────┤
│ いれるところ ●こーど  │ コンソール出力領域                   │
│  ○えーあいへのおはなし├──────────────────────────────────────┤
│ ひらがな入力パネル    │                                      │
├───────────────────────┤ テキストエディタ                     │
│ フォルダエクスプローラ │                                      │
│                       ├──────────────────────────────────────┤
│                       │ AIチャット  [モデル▼] 状態 [あたらしいかいわ] │
│                       │ ┌──────────────────────────────────┐ │
│                       │ │ 会話履歴（読取専用）             │ │
│                       │ ├──────────────────────────────────┤ │
│                       │ │ こうほコード プレビュー / 状態   │ │
│                       │ ├──────────────────────────────────┤ │
│                       │ │ 添付内容 / 入力欄（複数行）      │ │
│                       │ │ [そうしん][ちゅうし][まつびについか]│ │
│                       │ └──────────────────────────────────┘ │
├───────────────────────┴──────────────────────────────────────┤
│ 状態: ファイルパス / UTF-8 / 未保存 / 行・桁                  │
└──────────────────────────────────────────────────────────────┘
```
####  ひらがな入力パネルの出力先切り替え

ひらがな入力パネルの出力先を「コードエディタ」と「AIチャット入力欄」から利用者が選べるようにします。児童が同じパネルでコードも、AIへの話しかけも入力できるようにするためでございます。

```text
ひらがな入力パネル（左上）
┌────────────────────────────────────────┐
│ いれるところ： (●)こーど   ( )えーあいへのおはなし │
├────────────────────────────────────────┤
│ [ひらがな][かたかな][かず][きごう]     │
│ ...（v3の4.1の2行目・3行目）            │
└────────────────────────────────────────┘
```

### 日本語入出力の方針

日本語本文は次の全区間で同一内容として保持します。

```text
チャット入力（WPF TextBox）
  → ChatViewModel（.NET文字列＝UTF-16）
  → Foundry Local SDKへの要求（メッセージ）
  → ストリーム応答
  → ChatViewModel
  → 履歴表示
```
