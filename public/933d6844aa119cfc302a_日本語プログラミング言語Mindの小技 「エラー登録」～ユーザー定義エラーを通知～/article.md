>　Mindのライブラリ内部には、このようなエラー処理を支援するいくつかの単語が定義されている。これらについて以下に解説する。
>　
構文　＝　エラー？　→　＜真／偽＞
>　
 エラー処理を行うような処理単語の実行によってエラーが発生したかを調べる機能である。

 ～略～
>　
構文　＝　＜文字列＞を　エラー登録　→　・
>
>ユーザー自身が、エラー発生するような処理単語を定義する場合、指定するメッセージをエラー文字列として登録できる。これによって、その処理単語を利用する側が「エラー？」を実行したときに真が返されるようになる。

 
本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。

# 小技の解説
Mindの小技「エラー登録」とは、処理単語内でエラーが起きたとして呼び出し側に通知する機能です。処理単語内でエラーに相当する状態が起きた場合、ユーザー定義の文字列をこの単語で登録しておけば、処理単語を実行した後に「エラー？」という単語で検知できるようになります。

エラーが発生したとされる時にコンソールへ表示する文字列を指定します。

>構文＝　＜文字列＞で　エラー登録　　→　・　

エラー登録を行う処理単語内では冒頭次の構文でエラー状態をクリアすることが推奨されています。

>構文＝　エラークリア　→　・
 
次の記事で紹介している「重大エラー」を使えば、このエラー文字列を指定してプログラムを強制終了することもできます。

https://qiita.com/mylifewithviolin/items/faf6a378100bd4b731f3

# Mindプログラムソース
```mind:registerror.src
チェック値が０ならばエラーにしてますとは （チェック値　→　・）
        チェック値は　変数
    チェック値に　入れ
    エラークリアして
    「処理単語の実行が開始されました。」を　一行表示し
    「チェック値：」を　表示し チェック値を　数値表示し　改行し　
    チェック値が　０に　等しい
    ならば
    「エラーが発生しました。0はちょっとダメなんです。」で　エラー登録し　終わり
    つぎに
    「10をチェック値で割った値：」を　表示し
    １０を　チェック値で　割り　数値表示し　改行し
    「処理単語の実行が正常終了しました。」を　一行表示すること。

メインとは （・　→　・）
    「プログラムの処理が開始されました。」を　一行表示し
    ０で　チェック値が０ならばエラーにしてます
    エラー？
    ならば　エラー文字列で　重大エラー
    つぎに
    「プログラムの処理が正常終了しました。」を　一行表示すること。
```

0で除算した場合はMindのランタイム側で組み込みエラー文字列を表示して重大エラーとなりますが、ここでは０除算を事前にチェックしてエラーとする例にしています。

つづいて実行してみます。

## Mind7/8/9β
Mind8の結果です。記述は割愛していますがMind7/9βも同じです。

```cmd:
C:\developments\vscode\mind9>registerror
プログラムの処理が開始されました。
処理単語の実行が開始されました。
チェック値：0
エラーが発生しました。0はちょっとダメなんです。

C:\developments\vscode\mind9>
```
いかがでしょうか？イメージがつかめれば幸いです。

ソースコードの下記のヶ所で０を２に修正して実行するとプログラムは完走します。
```mind:criticalerror.src
メインとは （・　→　・）
    ～略～
    ２で　チェック値が０ならばエラーにしてます
    ～略～
```

```cmd:
C:\developments\vscode\mind9>criticalerror
プログラムの処理が開始されました。
処理単語の実行が開始されました。
チェック値：2
10をチェック値で割った値：5
処理単語の実行が正常終了しました。
プログラムの処理が正常終了しました。

C:\developments\vscode\mind9>
```
処理単語内でエラー登録を実行すると単語の外でエラー判定できることがわかります。プログラムの実行を終わらせるかどうかはプログラムの実装（書き方）次第となります。

上記の例ではエラー登録した後にすぐに単語の処理を終わらせる「終わり」を実行し、エラー？で判定した後は「エラー文字列」と「重大エラー」でプログラムを強制終了しています。
