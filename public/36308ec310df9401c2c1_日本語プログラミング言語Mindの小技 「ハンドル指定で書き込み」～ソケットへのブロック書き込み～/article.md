# はじめに
日本語プログラミング言語Mindの小技「ハンドル指定で書き込み」について説明したいと思います。

# 対象読者
日本語プログラミング言語Mindのユーザー、または日本語プログラミング言語に興味のある方

# この小技に関連するMind言語マニュアル

この小技に関連するMind言語仕様の記述はMind8プログラミングマニュアルに記載はありません。

Mind7の付属の上級者向けドキュメントmind7\doc\file.docmとsocketlib.docmに記載があります。

file.docm
Ｆ７．　パイプ
￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣
>　パイプに対して（あるいは１番の標準出力デバイスに対して）データを書き込むの
に、もちろん論理ファイルを設定して正規に「オープン」してから書き込みしても良いのですが、もう少し簡素な方法を用意しています。
>
>■ハンドル指定で書き込み　（Ver.7新規）
　　－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－
　　＜文字列情報＞を　＜ハンドル＞に　ハンドル指定で書き込み　→　・
　　－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－
　ある文字列を（バイナリのメモリブロックでも構いません）指定したハンドルのデバイスに書き込みします。バッファリングは無いので直ちに反映されます。
　エラーリターンがあるので必要に応じてエラー検査してください。
>

socketlib.docm
２－１　ソケットとファイル
￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣
>　しかし、簡単にソケットをアクセスできるよう（実はパイプにおいても同様のことが言えますが）、Version 7 以降では「ハンドル指定で・・」という系統の処理単語を使うことで、ハンドルレベルのままデータの読み書きを行うことができるようになっています。
　たとえば、
>
>　　　　○○構造体を　ソケット１に　ハンドル指定で書き込み


本機能（本記事）は、下記のバージョンに対応しています。Mind８のLinux版も対応していると思いますが、本記事では特に検証を行っておりません。

# 小技の解説
Mindの小技「ハンドル指定で書き込み」は、Mindのファイル・パイプ・ソケットといったハンドラレベルの標準出力ライブラリ機能の１つです。これに関連した単語は他に下記もあります。
「ハンドルとサイズ指定で構造体に読み出し」

file.docm
Ｆ７．　パイプ
￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣￣
>■ハンドルとサイズ指定で構造体に読み出し　（Ver.7新規）
　　－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－
　　　　　　　　　　　　　　　　　　　　　　↓「に」or「へ」必須
　　　　＜ハンドル＞　＜サイズ＞　＜構造体＞に
　　　　　　　　ハンドルとサイズ指定で構造体に読み出し　→　・
　　－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－－
　ハンドルとサイズ、さらに構造体を指定し、その構造体にデバイスから読み出したデータを格納します。（先頭番地から詰めます）
　ファイルハンドルとサイズはスタック渡しできますが、構造体名は記述必須です。


本記事では、ソケット通信アプリケーションとして実装し、サーバー側とクライアント側で共通の構造体を定義することで、ソケットへのブロック書き込み、読み出しを実装してみます。送信しているデータはクライアントでのコンソール入力の文字列ですが、構造体を介してブロックデータとして送受信しています。

# 実行結果
つづいて実行してみます。Mind8の結果ですが7/9βも同様です。

コマンドプロンプトターミナルは２つ起動しておきます。
サーバー用１つ、クライアント用１つです。
※注意　お手数ですが、それぞれのターミナルでビルドしたMindのバージョンのランタイムパスをとおしておいてください。

最初にサーバーを起動します。

```cmd:
c:\developments\vscode\mind9>socketsrv5
ソケット通信サーバー側を起動しました。クライアントからの接続を待機しています。

```
つづいてクライアント側を起動します。

```cmd:
C:\developments\vscode\mind9>socketclt5
ソケット通信クライアント側を起動しました。

```
このとき、サーバー側では下記のように接続確立のメッセージが表示されます。

```cmd:
C:\developments\vscode\mind9>socketsrv5
ソケット通信サーバー側を起動しました。クライアントからの接続を待機しています。
クライアント１との接続を確立しました。クライアント１からの送信を待機しています。

```

クライアント側でコンソールからメッセージを入力します。下図はEnterキー押下前です。
```cmd:
C:\developments\vscode\mind9>socketclt5
ソケット通信クライアント側を起動しました。
こんにちは。

```
クライアント側でEnterキー押下すると、サーバーがメッセージをおうむ返ししてきます。

```cmd:
C:\developments\vscode\mind9>socketclt5
ソケット通信クライアント側を起動しました。
こんにちは。
受信データ＝こんにちは。

```
サーバー側もメッセージを受信したことがわかります。
```cmd:
c:\developments\vscode\mind9>socketsrv5
ソケット通信サーバー側を起動しました。クライアントからの接続を待機しています。
クライアントとの接続を確立しました。クライアントからの送信を待機しています。
受信データ＝こんにちは。

```

クライアント側で数回メッセージを送信し、Enterキーのみ押下して終了します。
```cmd:

ソケット通信クライアント側を起動しました。
こんにちは。
 受信データ＝こんにちは。

 受信データ＝お元気ですか？
失礼します。
 受信データ＝失礼します。

ソケット通信クライアント側を終了しました。

C:\developments\vscode\mind9>

```

サーバー側もメッセージを受信して終了したことがわかります。
```cmd:

ソケット通信サーバー側を起動しました。クライアントからの接続を待機しています。
```
