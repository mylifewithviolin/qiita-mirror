# はじめに
日本語プログラミング言語Mind は今年2024年で生誕39周年。Mindが生誕した1985年にはどんなコンピュータ(パソコン・ワークステーション)が同時代にあったのか調べてみました。あなたの知らないいにしえのパソコンstoriaがいま始まる。


# CPU
## 80X86
* インテル 8086 1978年 16bit
* インテル80286 1982年 16bit
* インテル80386 1985年 32bit
* インテル80486(486DX) 1989年 32bit
日本ではNEC9800シリーズ セイコーエプソンPC-286シリーズ（その陰で富士通・日立など日本の御三家もだまっていなかったがNEC一強の時代が続いた）

## MC68000
* モトローラ MC68000 1980年 16/32bit
* モトローラ MC68020 1984年 32bit
* モトローラ MC68030 1987年 32bit
むかしのMACとかシャープのX68000シリーズ

## SPARC
* サン・マイクロシステムズ SPARC 1987年
正統なるUNIXマシーン搭載プロセッサ

# パソコン・ワークステーション

## NEC9800シリーズ
* PC-8801 1982年 8bit
* PC-9801 1982年 16bit NEC μPD8086（8086互換）5MHz RAM 128KB
* PC-9801VM 1985年 16bit NEC V30 (8086上位互換) 8M/10MHz
* PC-9801RA 1988年 32/16bit 80386 16MHz / V30 8MHz RAM 1.6MB

## EPSON PC-286シリーズ
* PC-286 1987年 16bit 80286 10MHz
* PC-386 1988年 32bit 80386 20MHz

## 富士通 FM-16βシリーズ
* FM-16βFD 1984年 16bit 80186 8MHz RAM 512KB
* FM-16βFDⅡ 1986年 16bit 80286 8MHz RAM 1MB

## Apple Macintoshシリーズ
* Macintosh 128K 1984年 MC68000 7.8MHz RAM 128KB
* Macintosh SE 1987年  MC68000 7.8MHz RAM 1MB
* Macintosh SE/30 1989年  MC68030 16MHz RAM 1MB

## Sun SPARCstationシリーズ
* SPARCstation 1 1989年 富士通 MB86901A/LSI L64801(いずれも製造元違いのSPARC) 20MHz RAM 64MB
