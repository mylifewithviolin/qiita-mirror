# この小技に関連するドリトル言語マニュアル

技術資料 - 標準オブジェクト - 多倍長整数オブジェクト からの引用

>多倍長整数オブジェクトは、大きな整数を表すオブジェクトである。数値オブジェクトは有効数字が17桁程度であるため、数十桁以上の巨大な整数値を扱うときは多倍長整数を使用する。多倍長整数の値は、次の例のように、文字列に大きい整数にするを送り生成する。
 x＝"1000000"！大きい整数にする。
 
# 小技の解説
ドリトルは教育用言語として設計されていますので細かい各種整数型の指定は基本的にないのですが、大きな整数型として多倍長整数に対応しています。
多倍長整数のような型はC# や Java のような高級言語でも、「桁を配列で持ち、筆算をそのままプログラム化する」ことで実装できます。ドリトルの実装はJavaなのでJavaのBigIntegerが使われている可能性がありますが実際は不明です。

多倍長整数の内部は次の 3 つで成立しています。
・桁を配列で保持する
・筆算の加算・減算・乗算・除算を配列で実装する
・符号（正/負）を別に持つ

本記事では、多倍長整数を使用した例として「階乗」の計算を実装してみます。この記事のポイントとしては、多倍長整数型のオブジェクトを、文字列のグローバルなインスタンスで作成するのではなく、再帰呼び出し関数の引数として使われる場合、どのように引数の型を多倍長整数型とコンパイラに認識させるかといったあたりとなります。

「大きい整数にする」は文字列オブジェクトのメソッドのため、「階乗を求める」の引数「値」に空列を加えて、まず「値」は文字列オブジェクトになることをコンパイラに知らせます。これにより「値」は「大きい整数にする」が使えるようになります。

```
多倍長値＝値！大きい整数にする。
```
「階乗を求める」のローカル変数「多倍長値」は上記の構文で多倍長変数オブジェクトが代入されることで多倍長変数オブジェクトとなります。
